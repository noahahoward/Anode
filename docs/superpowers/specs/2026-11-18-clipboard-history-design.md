# Clipboard History (Beta Features)

Written 2026-11-18, on the branch `clipboard-history`. Built, installed and checked on the owner's Mac the same day.

## What it is

Anode remembers what you copy. **Globe (fn) + Space** opens a search panel, drawn like Spotlight's (black at the top fading down into
liquid glass), over whatever you are doing. Type to search, **↑ ↓** to move, **↩** to paste the entry into the app you were in.
It is a Beta Features section, off until asked for.

## What you see and do

| Key | Does |
| --- | --- |
| ↩ | Paste into the app that was in front (⌘V is sent to it) |
| ⌥↩ or ⇧↩ | Paste as plain text |
| ⌘↩ | Put it on the clipboard only |
| ⌘1 … ⌘9 | Paste that row |
| ⌘⌫ | Delete the entry |
| ⌘P | Pin it (pinned entries are listed first and are never dropped by the time or count limits) |
| esc | Clear the search; a second esc closes the panel |
| a click anywhere else | Closes it |

The panel is a non-activating panel: Anode never becomes the active app, so the app being pasted into stays in front. It fades
in and out. Each row has the source app's icon (an image's own picture, a file's icon), the first line, and
"detail · app · time ago" under it. "link", "image", "file" and "text" are searchable words as well as the text itself.

The section (Settings → Beta Features → Clipboard History) has: the switch; the status line; the shortcut (changed in Shortcuts…, where
Globe can be recorded); how long entries are kept (30 minutes … 90 days, or forever; a day by default); how many (10 to 5000, 500);
keep images; pause recording; the apps whose copies are never recorded (added to the password managers that always are); Open
Clipboard History; Forget Everything.

## What is never recorded

Privacy comes first, and the rules are in `ClipboardPrivacy` (PowerKit) and applied twice: by the watcher before any data is read, and
by the store itself.

- Copies marked by their app as private: `org.nspasteboard.ConcealedType`, `TransientType`, `AutoGeneratedType`, the markers of text
  expanders and 1Password (`nspasteboard.org`), and `com.apple.is-remote-clipboard` (Universal Clipboard, which is fetched only when
  pasted). The markers are never stored with an entry either.
- Copies made in password managers (Passwords, Keychain Access, 1Password, Bitwarden, Dashlane, LastPass, KeePassXC, Enpass, NordPass,
  Proton Pass, and any app whose bundle id names one), and in apps on the person's own list.
- Anything copied while recording is paused, the screens are asleep or the session is locked: when watching starts again the pasteboard
  is taken as already seen.
- Anything over 10 MB (an entry bigger than that is kept in its essential forms only if those fit), and the whole history is capped at 200 MB.

What is kept is in `~/Library/Application Support/Anode/clipboard-history/`: the folder is 0700, `index.json` and every stored form
0600, and nothing is written until the first copy is recorded. An index that cannot be read starts again empty; a stored form no entry
owns is removed at launch. The log (`clipboard.log`) holds kinds, reasons and bundle ids, never what was copied. The uninstaller removes
the folder with the rest of Anode's data (`--data`).

## How it works

- `PowerKit/ClipboardHistory.swift`: the entry, the rules above, `ClipboardBuilder` (what a copy is: file, link, text, image),
  `ClipboardStore` (the entries, newest first, on disk; the age, count and size limits), `ClipboardSearch`.
- `PowerKit/ClipboardWatcher.swift`: looks at the pasteboard's change counter once a second (with half a second of tolerance); the
  contents are read only after the type strings and the app in front pass the rules. Anode's own write when pasting is marked as its own.
- `AnodeApp/ClipboardHistoryController.swift`: when anything runs (nothing while the setting is off; the timer stops while paused,
  asleep or locked); opening, choosing, deleting, pinning. Everything that touches the Mac is a closure, so it is tested with fakes.
- `AnodeApp/ClipboardPasteboard.swift`: the only code that touches `NSPasteboard.general` and posts a key. ⌘V is sent with ⌘ as the
  only modifier (a Globe key still held does not go with it), to the key that types "v" on the layout in use.
- `AnodeApp/ClipboardPanel.swift`, `ClipboardHistoryFeature.swift`, `ClipboardHistoryRuntime.swift`: the panel, the section, the wiring.
- Shortcut: `Shortcut` gained a Globe bit (`function`). It counts except on the keys that carry the fn flag themselves (arrows,
  function keys, Home, End, Page Up and Down, Forward Delete), so the existing shortcuts are unchanged.

## Measured on this Mac (macOS 27.3)

- macOS lets Anode read the pasteboard without asking (`accessBehavior` is "always allowed" for it); the log says so each time it is turned on.
- ⌘V sent as above pastes into a plain window; a window with no Edit menu ignores it (the test window had to be given one).
- The panel opens centred, 680 wide, its top edge a fifth of the way down the visible screen, at window level 101.

## Not done, and why

- **The panel is not measured against Spotlight.** This Mac's Spotlight cannot be launched from outside (`open` fails; a posted ⌘Space
  opens nothing), so every number in `ClipboardPanelMetrics` is an estimate, and the fade durations too. They are all in that one enum.
- Whether releasing Globe after Anode swallows the Space still triggers macOS's own Globe action (the emoji picker, or dictation) cannot
  be tested with posted keys: it needs the real keyboard.
- Image and file entries are listed and pasted, but image search is by the word "image" only (there is no OCR).
- A copy of Universal Clipboard content is never recorded, so it cannot be searched.
